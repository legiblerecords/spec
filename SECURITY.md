# Security

Legible Records files often hold sensitive security records, and its tools parse untrusted input. If you find a problem that could expose data or let a crafted file do harm, report it privately rather than in a public issue: use GitHub's private vulnerability reporting on this repository (Security, then "Report a vulnerability").

Expect an acknowledgement within five working days. Please give us a reasonable time to fix a problem before you publish it.

Never include real records, evidence or personal data in a report or an issue. Use invented examples.
